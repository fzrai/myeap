## 入门

### 前提条件

- 已安装Docker和Docker Compose
- 了解基本的半导体制造流程

### 快速启动

```bash
# 克隆仓库
git clone https://github.com/your-org/myeap.git
cd myeap

# 启动服务
docker-compose up -d

# 访问系统
open http://localhost:8000
```
